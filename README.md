# Terrarium

Modelo 3D interactivo del ecosistema cerrado "Terrarium", propuesta del equipo para el reto de elemento TIERRA del Mars Challenge 2026 (The Grand Jam 2026).

## Que es

Terrarium es un domo geodesico autorregulado en Marte, dividido en tres zonas biologicas interconectadas:

- **Produccion vegetal** - genera oxigeno y alimento.
- **Cultivo acuatico** - filtra agua y aporta proteina.
- **Compostaje** - convierte residuos organicos en nutrientes.

Un sensor central monitorea agua, nutrientes y gases en tiempo real y ajusta automaticamente los flujos entre zonas, reduciendo la dependencia de supervision humana constante.

## Ver el modelo

Abre `index.html` en un navegador, o visita la version publicada en GitHub Pages una vez activada.

Pasa el cursor sobre cualquier elemento (domo, zonas, plantas, sensor, tuberias) para ver su nombre y funcion.

## Stack

- Three.js (r128) via CDN, un solo archivo HTML autocontenido, sin dependencias de build.
